1. Classical Definition of Semaphore

A Semaphore S is an integer synchronization tool that, apart from initialization, is accessed strictly through two standard atomic operations: wait() (or P, from Dutch proberen, "to test") and signal() (or V, from verhogen, "to increment").

Atomic wait(S) Operation
wait(S) {
    while (S <= 0)
        ; // busy wait (spin-lock)
    S--;
}
Atomic signal(S) Operation
signal(S) {
    S++;
}

2. Peterson's Solution (Software Synchronization)

Peterson's solution is a restricted classic software solution for two processes (P0 and P1). It shares two shared data variables:

  • int turn; — Indicates whose turn it is to enter critical section.
  • boolean flag[2]; — Indicates if a process is ready to enter critical section (flag[i] = true).

3. The Bounded-Buffer (Producer-Consumer) Problem

Uses three semaphores to maintain consistency across a buffer pool of N slots:

mutex = 1

Binary semaphore protects buffer access.

empty = N

Counting semaphore for available empty slots.

full = 0

Counting semaphore for filled data slots.
