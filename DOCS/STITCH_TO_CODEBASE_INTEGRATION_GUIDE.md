## 2. TypeScript Contracts & Props Wiring

When Stitch outputs React/TSX components, ensure their data shapes adhere to the existing TypeScript contracts defined in `src/types/academic.ts`:

### 2.1 Academic Resource Contract (`ResourceCard`)
```typescript
import { AcademicResource, ResourceType, VerificationStatus, ExamRelevance } from '@/types/academic';

export interface ResourceCardProps {
  resource: AcademicResource;
  onBookmarkChange?: () => void;
  onSelectTopic?: (topic: string) => void;
}
```

Key fields consumed by Stitch generated cards:
- `resource.title`: String (displayed in Source Serif 4).
- `resource.type` / `resource.resourceType`: `'video' | 'notes' | 'revision_pdf' | 'past_paper'`.
- `resource.source`: E.g., `"MIT OpenCourseWare"`, `"NPTEL IIT Madras"`, `"JNTUH Faculty Notes"`.
- `resource.curriculumMatch`: Number `0-100` (e.g. `96%`).
- `resource.verificationStatus`: `'verified' | 'pending' | 'outdated'`.
- `resource.anchor_resource`: Boolean (triggers golden border and star badge).
- `resource.exam_relevance`: `'high' | 'medium' | 'low'`.
- `resource.time_to_consume`: `'15 min' | '30 min' | '45 min' | '1 hr' | '3 hr' | '6 hr+'`.

### 2.2 Course Hierarchy Item (`Course Page & Library`)
```typescript
import { CourseHierarchyItem, CourseHierarchyUnit } from '@/types/academic';

export interface CoursePageProps {
  course: CourseHierarchyItem;
  activeUnitIndex?: number;
}
```

Key fields:
- `course.code`: Monospace code (e.g. `CS501PC`).
- `course.name`: String (e.g. `Operating Systems`).
- `course.regulation`: String (e.g. `R22`).
- `course.units`: Array of units with topics and sub-resources.

## 3. Connecting Stitch UI to Genkit AI Flows & Server Actions

Stitch generates interactive search boxes, buttons, and chat interfaces. Wire them to the existing backend server actions:

### 3.1 AI Discovery Action (`/discover`)
Wire the search form button in Stitch's Discovery Console to `discoverResources`:

```typescript
import { discoverResources } from '@/app/actions/discovery';
import { useInstitution } from '@/hooks/use-institution';

// Inside your Stitch-generated Discovery component:
const { subdomain } = useInstitution();
const [isLoading, setIsLoading] = useState(false);
const [results, setResults] = useState(null);

const handleSearch = async (query: string) => {
  setIsLoading(true);
  try {
    const data = await discoverResources(query, subdomain);
    setResults(data); // data contains: queryAnalysis, resources (6 items), coverageReport, syllabusMap
  } catch (error) {
    console.error('Discovery failed:', error);
  } finally {
    setIsLoading(false);
  }
};
```

### 3.2 AI Tutor Chat Flow (`/chat`)
Wire Stitch's chat input and starter cards to `submitChatMessage`:

```typescript
import { submitChatMessage } from '@/app/actions/chat';

const handleSendMessage = async (text: string) => {
  const response = await submitChatMessage(text, chatHistory);
  // Appends tutor response with verified academic citations to the message stream
};
```

## 4. Multi-Tenant Institution & Authentication Hooks

Every Stitch page that displays the university name, logo, or user avatar connects to these two existing hooks:

### 4.1 Subdomain & University Context (`useInstitution`)
```typescript
import { useInstitution } from '@/hooks/use-institution';

export function HeaderWidget() {
  const { institution, subdomain, switchInstitution, availableInstitutions } = useInstitution();
  
  return (
    <div className="font-mono text-xs uppercase tracking-wider text-muted-foreground">
      {institution.shortName} Academic Repository • {institution.regulations.join('/')} Compliant
    </div>
  );
}
```

### 4.2 User Role & Auth State (`useAuthRole`)
```typescript
import { useAuthRole } from '@/hooks/use-auth-role';

export function AuthNavSection() {
  const { isLoggedIn, isStudent, isFaculty, isAdmin, user, logout } = useAuthRole();
  
  // Conditionally display Faculty moderation queue button
  if (isFaculty || isAdmin) {
    return <Link href="/admin/dashboard">Faculty Review Queue</Link>;
  }
}
```

## 5. CSS Classes & Styling Checklist for Stitch Imports

When Stitch produces Tailwind CSS code, ensure it uses the custom variables already configured in `src/app/globals.css`:

1. **Theme Tokens:**
   - Backgrounds: `bg-background` (`#E4D7B0`), `bg-card` (`#E7DBBF`), `bg-popover` (`#F3EAD2`).
   - Text: `text-foreground` / `text-ink` (`#5C4B3E`), `text-muted-foreground` (`#85766A`).
   - Primary: `bg-primary` (`#8D9D4F`), for small buttons use AA override `bg-[#5F6F2E]`.
   - Borders: `border-border` (`#B19681`).
2. **Typography Classes:**
   - Headings: `font-serif font-bold tracking-tight text-balance`.
   - Body: `font-sans`.
   - Codes & Badges: `font-mono uppercase text-xs`.
3. **Effects:**
   - Paper noise: Add `bg-paper` to main layout wrappers.
   - Diffused shadow: Add `shadow-academic`.
   - Smooth entrance: Add `animate-ink`.
